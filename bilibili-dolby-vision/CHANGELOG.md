# 版本记录

## 6.0.0 — 2026-11-05

- 支持右侧推荐列表复用播放器时，在实际切换前预检新视频。
- 按新 BV / CID / 分 P 关联播放信息，不再依赖首次页面的旧状态。
- 支持播放器切换先于 URL 更新的情况，并处理站内路由与前进后退。
- 连续快速切换视频时取消过时切换，避免旧操作影响后来的视频。
- 保留首次打开预检、长期缓存和自动恢复播放器。
- 整理独立目录、通用 Windows Edge 启动器、使用说明和 32 项可离线运行的逻辑检查。
- 当前只对 P8.4 做自动修正；P8.1 尚未扩展支持。

## 5.0.0

- 在播放器首次连接前等待元数据预检。
- 修复媒体 CDN 未暴露 `Content-Range` 时错误跳过有效初始化段的问题。
- 识别晚到时，尝试完整重建播放器并恢复播放进度、暂停状态。

## 4.0.0

- 增加初始化段预检。
- 取消固定的 24 小时缓存过期时间，按实际流身份核实缓存。
- 尝试通过自动切换画质应用新识别结果；该方式不能覆盖所有首次播放路径，后续由播放器重建替代。

## 3.0.0

- 根据实际初始化元数据学习并缓存 P8.4 配置。
- 在下一次创建缓冲区时应用修正；首次识别后仍可能需要重载。

## 早期实验版本

最初使用固定测试视频或尝试播放中 `changeType`。后者在本次 Edge / Media Foundation 环境被拒绝，未作为最终方案保留。
